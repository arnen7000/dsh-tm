# 开发需求说明书（v1.1）

> **这份文档做什么**：把 2026-11-01 ~ 11-02 期间用户提出的全部需求汇总成可验收的条目。
> 后续开发与测试都以本文件为准；**每条需求都有明确的验收标准**。
>
> **状态标记**：✅ 已实现 / 🟡 部分实现 / ⬜ 未实现 / ❌ 已废弃

---

## 0. 产品定位（不变）

- 不注册环境变量，解压即用
- 轻量、严谨、靠谱
- 非管理员权限完成全部功能
- 面向 Windows 10/11

---

## 1. 功能需求

### 1.1 版本槽管理

| # | 需求 | 验收标准 | 状态 |
|---|---|---|---|
| F1 | 最多 6 个槽并存 | `MAX_SLOTS = 6`，管理器与 CLI 两处一致 | ✅ |

## 4. 已知问题与教训

| 问题 | 教训 |
|---|---|
| 删除了用户有意设置的 `D:/DSHTMer` 目录 | **删除任何目录前必须向用户确认**；不能把"看起来像测试残留"当作判断依据 |
| 多次出现"改了 A 弄坏 B" | 每次改动后必须实机验证，不能只跑测试 |
| 定义顺序导致的 NameError 反复出现 | `.pyw` 静默失败，必须用静态检查兜住 |
