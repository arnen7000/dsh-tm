# DSH-TM v0.1.15 验收记录

2026-11-26 在 Apple Silicon、macOS 27.0.1 上运行解包后的 arm64 发布候选。使用单独的配置、HOME、环回端口 43835 和真实 dsh `0.2.0-rc.2` 安装。以 `dsh-versions` 作为安装根，构造旧版可能写出的重复目录登记，并在隔离数据目录内放置两份校验文件。

| 成品界面操作 | 实测结果 |
| --- | --- |
| 从错误登记直接卸载 | 确认窗显示登记路径。后台拒绝卸载，结果窗和日志都给出缺失目录，原槽仍保留。 |
| 扫描并纳入 | 候选显示实际旧槽和原地接回。确认重用 `v3` 及端口 43835，原地修正路径并生成三份启动脚本。卡片显示真实版本，后续体检正常。 |
| 启动并取消卸载 | 真实 dsh 从成品界面启动并监听端口。选择取消后窗口显示槽仍在运行。 |
| 确认卸载 | 成品停止该进程，核对九个备份文件，再删除整个槽目录。结果窗和日志均显示释放 568.4 MB 与备份位置。两份校验文件逐字节比对通过，备份包含 npm 清单和版本记录。槽卡片及配置条目消失，端口释放，设置和安装位置入口可用。 |

上述操作使用成品窗口的键盘焦点与原生弹窗，采用真实安装、真实文件写入与删除。接回后的日志检查确认成功链路没有体检错误、空备份误报或异常堆栈。24 套本机回归覆盖共享规则，包括有损坏路径的旧登记恢复、安装根等于版本根、缺槽内 Node 的候选拦截和批量部分失败。

旧槽接回的完整桌面链路实测环境为 Apple Silicon macOS 27.0.1。发布页列出 GitHub 托管 macOS 15 双架构和 Windows x64 的各自测试步骤。macOS 13.5、实体 Intel Mac、物理双屏和普通 Windows 10／11 桌面的同等图形化操作仍待实机覆盖。
